Extraction Requirements:

- Extract ALL inclusion and exclusion criteria present in the text.
- Each criterion must be kept exactly as written (no rewriting or interpretation).
- If a criterion contains multiple independent conditions, split them into separate entries.
- Ignore any text that is not a clear eligibility criterion.
- Do not add missing information or infer new criteria.
- Avoid duplicates.
- If a section (inclusion or exclusion) is not present in the text, return an empty list for that section.

Cohort Assignment Rules:

- Criteria listed before any cohort heading are general and apply to all cohorts: set cohort_id to null.
- Criteria listed under a cohort heading (e.g. "Cohort 1a:", "Cohort 2b:") are specific to that cohort: set cohort_id to the exact ID from the known cohorts list.
- If a criterion explicitly references multiple cohorts by description (e.g. "combination therapy cohorts"), create one entry per applicable cohort.
- Only expand to multiple cohorts when the text explicitly targets a cohort subset.
- Do not infer cohort membership from medical concepts, treatment history, biomarker status, or subgroup descriptions unless the criterion explicitly references a cohort or cohort subset.

Cohort Scope Rules:

- A cohort heading starts a cohort-specific section.
- All criteria following a cohort heading belong to that cohort until:
  - another cohort heading appears, or
  - a new major section starts (e.g. Inclusion Criteria, Exclusion Criteria).
- Criteria that appear before the first cohort heading are general and apply to all cohorts.
- Criteria appearing after the last cohort heading but outside any clearly cohort-specific subsection should be treated as general unless the text explicitly references a subset of cohorts.

Section Header Rules:

- Section headers, category labels, numbering labels, and descriptive headings are not eligibility criteria and must not be extracted.
- Criteria listed under such headers inherit the same cohort scope as the surrounding section unless the text explicitly references a cohort subset.
